# Product Requirements Document

The canonical PRD is the master document supplied at project kickoff
("Central Company CRM — PRD v1.0"). It describes product vision, scope,
roles, modules (M1–M13), workflows A–D, data model requirements,
non-functional requirements, KPI definitions, integrations roadmap, phased
delivery plan, acceptance policy and success metrics.

Treat the master PRD + Master Prompt (Parts 1–17) together as the source of
truth. Conflicts are resolved per Master Prompt Part 4.

Any clarification accepted during the project lives in `docs/decisions/` as
an ADR.
